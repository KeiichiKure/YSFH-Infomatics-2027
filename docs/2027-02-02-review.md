# 02-02・2027年度形式への改訂

2026-11-04。作業先は2027年度リポジトリのみ。2026年度側の02-02と2027年度側は着手時点で内容が一致していた。2026年度側は参照のみ。

## 改訂範囲

- 02-01の拡大後に合わせ、本文・節末用語18px、最終一覧・主操作16px、学習節見出し36px。本文の最大幅1120px、最終一覧960px。
- 共通部品 `app/components/revision2027/` を導入。項目一覧は初期非表示で、開閉しても本文の幅と活動の状態を保つ。元のアンカーを維持。
- 節番号は1〜4、まとめは✓。元の最終一覧20語と定義をそのままデータへ分離。第1〜3節の従来の用語欄を「この節の重要語」に集約し、語句と意味で表示。「体験では」「例では」は設けない。第4節へ新しい用語を創作して追加していない。
- 最終一覧の見出し・案内を統一。20語の緑リンクと意味の開閉を別操作にする。
- グラフと設定、動画と操作、データ量の条件・画像・結果を並べる。計算式・入力範囲・再生の動作・出題内容は変更していない。

## ユーザー確認

改訂前の1280×720では標本化約1511px、色の混合約1140px、画素・階調約1565px、奥行き等約1798pxの枠だった。この4枠について質問し、ユーザーから「文字を大きく保ち、図と操作を近づけて縦に読み進める」と回答を受けた。1画面への段階分割はせず、必須情報を隠す内部スクロールも設けていない。この許可を他の活動・単元へ一般化しない。

## 確認内容

- 現行02-02、基準の02-01、異なる構造の05-02を実画面で参照。
- 1280×720、1366×768、1024×768、390×844でページ全体の横はみ出しなし。用語一覧はPC2列・スマートフォン1列。
- 実表示：本文18px、節末用語18px、最終一覧16px、節見出し36px。
- 最終一覧20語をすべて展開し、20個の節リンクをクリックして1〜3節の正しい移動先を確認。
- メニューの初期非表示、開閉、Escape、スマートフォンでボタン下に開く配置を確認。開閉しても本文と状態を保持する構造。
- 波の周波数20Hz・標本化8Hzで警告、標本化24000Hz・24bit・標本6個の拡大で図とラベルを確認。ラスタ・ベクタ32倍、RGB最大値とCMY最大値、階調1bitの変更を確認。
- 動画60fps・一時停止・前後のフレーム操作で、2204→2205→2204枚の変化を確認。遠近法・重なり・陰影の切り替え、視差の最大値、ARとMRの手の表示を確認。
- 音声の最大設定で34,560,000 B、静止画像1920×1440・RGB各8bitで8,294,400 Bを確認。KB/MB換算を保持。
- PCの独立した活動枠：ラスタ・ベクタ約595px、動画約633px、音声と静止画像の最大データ量は各約563pxで表示。許可された4枠は縦に読み進める。
- 公開用ビルド・型チェックと対象TSXのESLintを実施。2026年度版、他単元、既存の共通globals.cssを変更していない。

スマートフォンでは自然な縦スクロールを使う。VRの背景用の山は場面枠で意図的に切り取られる装飾で、ページの横はみ出しではない。
